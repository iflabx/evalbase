# 项目助手：方案执行与长任务恢复

2026-10-06。Owner 已授权根据最新“先设计方案，再执行”会话的审查结果逐项完成调研、文档、审查、开发和测试。本文补充 [优化合同](assistant-optimization.md)；原有账号权限、容量、字段保护、来源身份及人工采用/发布确认继续有效。

## 1. 问题与目标

实测会话在执行阶段成功建立一个空草稿并完成十次记录查询，未提交处理运行，随后报告 `assistant_result_incomplete`。十二次工具成功不代表方案完成。当前日志缺少模型结束原因，不能据此断言某一个模型停止条件。

用户能先要求方案、修改方案，再发送“开始执行”；助手应依照最新有效要求推进，预算用尽时保留进度并在授权内续做。长方案不能依赖用户逐轮发送“继续”，也不能把旧标签直接映射当作已完成语义分类。

## 2. 有界执行与恢复

- 保留每轮最多十个模型步骤、十二次工具调用、八十秒模型等待及现有并发上限；每段最多十二个自动续做回合，每会话最多一百回合。
- 接近单轮查询预算时结束这一段，服务端根据真实回执保存阶段总结与未完成步骤。模型汇总失败不能抹掉已成功操作，也不能将未完成目标显示为完成。
- 只有当前有效任务明确处于执行模式、存在未完成步骤且本轮取得新进展时，才安排预算续做；纯解释、只给方案、等待补充、等待确认、停止或失败不会自动开始新的业务操作。
- 自动续做在既有任务修订、权限、依赖和执行令牌约束下进行；事件由数据库唯一操作键去重。恢复读取真实回执和保存的步骤，不重复建立草稿、提交处理或产生确认副作用。
- 没有新进展的反复查询不能无限续做；达到限额时保留结果，明确未完成范围并提供重试。停止、撤权和来源失效及时阻止续做。

## 3. 可执行方案与批处理

- 方案保存最新生效要求、步骤、当前步骤、真实结果引用以及计划/执行模式。模型不能自己宣称业务操作成功；步骤执行状态来自工具回执、作业终态和确认回执。
- 有编辑权限的任务已选用背景依据，却在连续查询后仍未保存步骤时，执行器在最后汇总前强制调用现有 `plan_task` 保存已确认要求、模式和非空步骤。未完成的检查点随回合持久保存，过期重领后继续校验，不接受空方案；内部标记不进入用户响应。待核对定义不能写成已确认分类；此边界不增加数据处理授权，查看权限的只读背景查询保持可用。
- 执行前检查步骤是否有对应业务工具和已定位对象；要求矛盾、缺少分类定义或缺少关键范围时应说明并澄清，不悄悄缩小方案。
- 已有标签与文档分类不一致时，保留原题和原标签，使用后台逐条判断并在处理结果中记录新增分类。预览工具只用于样例与统计，不能靠逐页聊天读取承担全量语义处理。
- 复用现有 Worker 分批、冻结输入、失败补齐和取消协议。分类、汇总、按规则选取和核对通过已保存结果衔接；后续步骤不得重新改写源文件或重复生成上一阶段候选。
- 分类体系来自用户背景，不硬编码安全题库。读取跨页章节时持续读取其剩余定义；GB 附录 A 的三十一细类用作本轮验收样例，不是产品内置分类。
- 背景读取返回 `nextFrom`，沿同一查询的匹配列表继续；省略查询时沿原文片段继续。片段 `index` 从一开始，与原文读取位置相同，PDF 页号仍是独立定位。无匹配明确返回导航提示，改读已有片段附近的原文；类别数量不能被解释为连续章节编号，分类层级与子项必须来自原文。
- 用户要求各类覆盖时，服务端核对实际缺失类别；允许值限制与覆盖要求分别保存。数量达标但缺类、配额不足、重复或格式错误不得显示结构核对完整。来源中缺少某类时报告缺口，不能制造来源数据或擅自改配额。

## 4. 反馈与诊断

- 当前任务卡显示实际步骤、已处理/待处理数量、等待原因和下一步；消息与历史操作保持折叠，视觉沿用 frontend-v1 donor。
- 单轮观察只保存结束原因、模型步骤数、工具次数、耗时和预算/错误代码，不记录凭据或任意数据正文。
- 区分阶段结束后续做、等待后台、等待人工、业务失败和模型协议失败；“已完成”须有实际成果和完整核对依据。

## 5. 验收

1. 公共 HTTP：先给方案不执行；执行后跨预算自动推进，已创建草稿只出现一次；用户更正替换旧要求。
2. 恢复和竞争：同事件重复调度、进程恢复、停止、撤权、来源删除及旧回合响应；均不重复写入或扩大授权。
3. 批处理：逐条分类保护原题和原标签，保存完整结果；失败仅补缺失；分类结果按规则选取后保留真实来源。
4. 完整核对：缺类、分类范围错误、配额不足、空题和重复明确报告，禁止错误采用确认。
5. Browser：当前步骤、进度、阶段结束与失败提示准确；相同会话完成“方案→执行→候选审核”，窄窗口和键盘操作可用。
6. 真实模型：以已提供背景和授权来源复验一个短请求的二百条目标；逐条内容抽查与全量结构核对分别记录，不以假模型通过代替真实效果。
