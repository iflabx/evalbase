# EvalBase 数据选取策略建议

日期：2026-10-04。已参考[原型说明](../prototypes/data-selection-vnext.md)及前轮审查。本轮只研究 Mock 选样，不修改正式合同。以下策略、优先级与交互建议均为**设计推断**；官方资料仅证明相关方法或工作流，建议不代表已实现能力。

| 策略 | 适用条件与建议 |
| --- | --- |
| 来源 / Metadata 分层 | **简单可做。** 按来源或已有分类分组，组内固定种子抽取；支持原比例或每组最低配额，显示取整与不足。[scikit-learn 分层方法](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.StratifiedShuffleSplit.html)保留分类标签比例；推广到来源是设计推断，不能保证统计代表性。 |
| 核心回归 + 失败补充 | **有人工失败标签即可做；分数驱动需要可信评分。** 保留旧版本核心，再补失败专项和普通随机样本，分别标记。[LangSmith 评测工作流](https://docs.langchain.com/langsmith/evaluation)将已发现失败加入测试集，以持续检查回归；无需接入该服务。 |
| 近期数据 | **有可信时间字段即可做。** 指定业务采集时间窗口，窗口内随机抽取；不要把上传时间等同业务发生时间。[Label Studio](https://labelstud.io/guide/manage_data)支持日期排序及已有预测分数排序。 |
| 边界用例覆盖 | **已有标签即可做。** 对长文本、多语言、缺失可选字段、少见业务类别设明确小配额，其余随机；避免把坏解析记录当边界用例。[LangSmith 数据管理](https://docs.langchain.com/langsmith/manage-datasets)支持 Metadata 筛选和子集评测；边界类别与配额由用户定义。 |
| 模型表现较差优先 | **需要可信评分。** 按同模型、同评测批次、同评分口径的低表现记录排序或阈值筛选；保留普通样本作对照。可借鉴上述分数排序，但问答评分不是概率。 |
| 模型不确定性 | **需要分类概率或经验证的不确定性指标。** [modAL](https://modal-python.readthedocs.io/en/latest/content/query_strategies/uncertainty_sampling.html)使用分类概率的最大值、前两类差值和熵；不能直接把开放式问答低分命名为“低置信度”。 |
| 语义多样性 | **向量 / 模型后续项。** 将文本转为固定版本的向量，聚类后分配名额；[KMeans](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.KMeans.html)输入为特征矩阵。簇内取代表记录是推断，模型、距离和簇数都会影响结果；已有业务分类分层可先覆盖部分需求。 |

**优先推荐三项：来源/Metadata 分层、核心回归 + 失败补充、边界用例覆盖。** 它们能分别控制来源分布、保留比较基线、覆盖少见情况。近期窗口可直接作为筛选条件；模型评分排序先以 Mock 体验，再验证真实评分来源。

本轮模型分数须标明“模拟”；未来若用 Mock 自动边界标签或簇标签，也应明确标识。预览显示选中理由、输入模型/批次及缺分数量，缺分不当零分；同分按稳定身份确定顺序，随机抽样才使用种子。沿用固定预览、人工调整、加入草稿的链路。

**低模型表现不意味着数据无效。** 失败专项、边界配额会有意改变分布，其汇总结果不代表原始整体；固定核心与新增专项宜分别比较。开放式问答表现分、不确定性和数据质量是三个不同维度。
