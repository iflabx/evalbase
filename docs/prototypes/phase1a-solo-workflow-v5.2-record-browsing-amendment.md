# 单人工作流原型 v5.2：记录浏览补充

2026-09-08，Project Owner 验收以下 `v5.2` 原型补充。它建立在
`66ba66b` / `prototype/solo-workflow-v5.2` 的浏览器内存 Mock 上；不修改
PRD、Architecture、ADR、Implementation Spec、Ticket 或正式实现。

## 已冻结的交互

1. 数据集文件、数据集“全部记录”和测试集版本记录均提供“紧凑 / 适中 / 展开”三种行高。
   行高只影响当前浏览器会话的阅读密度；刷新后回到紧凑，不保存为用户偏好。
2. 上传映射允许将多个原始字段映射为 Metadata。记录列表按“字段：值”保留这些字段边界，
   默认显示前两项；“+N 项”在原处展开完整键值，不把 Metadata 混成不可辨认的文本。
3. 记录详情以 `Metadata · N 项` 的键值列表显示全部 Metadata。测试集编辑通过“编辑 Metadata”
   对话框增删键值；同一记录中重复的 Metadata 字段名会被阻止。
4. 测试集记录筛选包含一个或多个来源文件、问题是否填写、原始资料/手工新增、Metadata 字段选择器
   （“全部字段”或当前实际字段）和“值包含”输入。不同筛选条件按 AND 关系同时生效；多选来源文件
   在来源条件内匹配任一项。界面显示可移除的已应用条件，例如 `Metadata · 分类包含“预约”`，并可清除全部。

## 明确不做

本补充不引入持久化阅读偏好、Metadata Schema 或类型系统、任意查询构建器、保存筛选器、
JSON 编辑器、批量 Metadata 编辑、权限、协作或新的正式产品合同声明。

正式实现前，必须先完成“冻结 v5.2 原型与正式合同、Ticket、当前实现”的只读差异审计；
审计确认的差异才可进入后续合同和 Ticket，不得把浏览器 Mock 直接当作实现授权。
