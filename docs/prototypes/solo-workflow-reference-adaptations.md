# Frozen Interaction Contract

The accompanying HTML prototype is the visible EvalBase workflow contract. It defines the page hierarchy, operation order, labels, dialogs, empty/error states, version branching, provenance browsing, downloads, and Trash behavior.

The formal application implements the same workflow with the Fastify API, PostgreSQL, MinIO, and `frontend-v3/`. Prototype data is browser-memory mock data only and is not product data.

Out of scope for this contract: login and multi-user collaboration, external sharing, arbitrary saved filters, version merges, advanced parsing products, external evaluation platforms, and additional visible workflows.
