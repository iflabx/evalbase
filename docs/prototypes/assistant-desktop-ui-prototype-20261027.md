# 项目助手桌面式静态交互原型

- 日期：2026-10-27。
- 目标：保留侧栏、消息/执行记录、输入区和右侧工作区，按用户最新要求统一为 frontend-v1 页面风格。
- 原型：[THROWAWAY-assistant-desktop.html](./THROWAWAY-assistant-desktop.html)。
- 依据：[开源界面复用调研](../research/assistant-workspace-ui-reuse-20261027.md)。
- 状态：待用户体验反馈；不是正式产品或组件接入验收。不修改 PRD、冻结原型和现有业务逻辑。

## 打开方式

直接用浏览器打开 HTML 文件即可；不需要安装依赖。也可在仓库根目录运行：

```sh
python -m http.server 4230 --bind 127.0.0.1 --directory docs/prototypes
```

然后访问 [本机预览](http://127.0.0.1:4230/THROWAWAY-assistant-desktop.html)。桌面宽窗口保留项目导航，助手页面内部为会话栏、消息区、工作区三栏。项目导航可收为图标栏，会话栏和工作区可独立收起；窄窗口使用抽屉。

本轮在用户本机的独立原型目录启动相同静态服务，绑定 127.0.0.1:4230。没有更新或重启 4217/4226。

## 可体验的内容

- 项目导航：保留当前项目、原始数据、测试集、项目助手、数据处理及设置；项目助手保持选中。其他入口仅展示提示，不连接业务页面。
- 助手内会话栏：新会话、搜索、按时间分组、当前项目内的示例会话切换和重命名。
- 中间：浅色用户气泡、正文/表格、执行记录展开、结果入口、复制回复。
- 输入：示例附件、示例模型切换、发送；Enter 发送、Shift+Enter 换行。
- 示例执行：约 7 秒的预设阶段动画，可停止和继续；不解析提示词，不调用模型。
- 右侧：点击文档或成果后，按实际内容名称打开标签；重复打开定位已有标签，可逐个关闭，关闭最后一个时收起工作区。Metadata 展开、桌面调宽与窄屏抽屉保留。
- 普通方案和执行记录：在消息区折叠展示；仅规划的会话显示未执行方案，不展示虚假的生成完成记录。
- 保存：模拟确认、修改草稿名称、显示保存结果；可下载 8 条静态 JSONL 样例。

状态仅存在当前页面内存，刷新即恢复。示例数据与执行时长已标识为模拟；所有发送都使用预设响应，不构成能力、质量或模型推理的验证。CSP 的 connect-src 为 none，页面没有模型或业务 API 请求。

## 实现边界

这一步用单文件 HTML/CSS/JavaScript 验证调研提出的组件组织和视觉方向，没有安装 assistant-ui、改应用路由或复用旧编排逻辑。后续若设计获确认，再按调研选择的组件实施正式接入；不能把本文件原样当成生产实现。

视觉令牌直接摘取 `frontend-v1/src/styles.css` 的 light `:root`；按钮、输入框、卡片、Tabs 分别对齐同目录 `components/ui/` 对应组件的 CSS 规则。静态 HTML 仅复用视觉规则，未声称接入 React/Radix 组件。移除独立的暖灰快捷栏，采用白色侧栏、48px 顶栏、冷灰内容底、蓝色主按钮、6px 控件与 12px 卡片圆角；字体使用 donor 原有字体栈。没有为原型引入账号、数据库、长期存储、真实上传、权限审批或预算系统。

## 按内容打开工作区（2026-10-27）

- 根据 Owner 确认，取消数据预览、方案、文档三个固定标签；使用具体文件名或成果名。未打开内容时默认收起。
- 标签按会话保存在页面内存，切换会话不混用内容；收起面板保留标签，关闭标签不删除样例，点击消息中的入口可重新打开。
- 普通方案直接留在消息区；执行记录仍可独立展开。没有新增侧边聊天、真实文件编辑或运行时接入。
- 模拟保存后，成果标签随草稿名称更新。该原型每个会话只有一个预设成果对象，不模拟多轮成果版本管理。
- 验证：浏览器检查文档/成果双标签、重复打开、切换与全部关闭、重新打开、会话隔离、普通方案、模拟保存后的名称，以及项目导航折叠。另通过窄屏抽屉、键盘左右切换、无页面横向溢出检查，浏览器错误日志为空；JavaScript 语法检查通过。

## 工作区入口修正

- 原因：无已打开标签时禁用了工作区切换按钮，导致首次进入与关闭全部标签后无法通过按钮打开。
- 修正：按钮始终可用；无标签时展示当前会话可打开的文档/成果入口，无内容时显示空态。保留默认收起及关闭最后一个标签自动收起。
- 验证：修复前浏览器返回按钮 disabled；修复后首次进入、菜单展开时点击、关闭全部后重新打开、新会话空态均通过，未接入真实接口。
