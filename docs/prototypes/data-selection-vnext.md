## 交互规则和限制

- 默认无条件；筛选与抽样始终针对选定文件的全部记录，预览每页 20 条。
- 按比例向下取整；候选不足时取全部候选并提示；人工排除后不自动补足。
- 数量与比例分别记住输入，默认 500 条 / 5%；切换单位不会把 500 条转换成 500%。比例旁显示当前可选数量、计算式及取整结果。
- 预览固定；分页、搜索和确认不重抽。同来源、规则、种子生成相同结果。“恢复原抽样结果”保留种子并撤销人工调整；“重新抽一批”更换种子。全部选取使用“恢复原选取结果”。
- 修改文件、筛选值、数量、比例或方法时，立即标记旧预览失效并禁用确认。旧预览和人工调整保留供核对，点击“更新预览”后才生成新结果；输入过程不移走光标。
- 确认区放在结果表格上方，显示已选、已在草稿及本次新增数量。新增为 0 条时禁用确认，已有记录不重复加入，也不增加空选取历史。
- 点击预览整行或用 Enter / 空格打开只读完整记录；复用已有弹层样式，展示问题、期望输出、完整 Metadata 和来源。关闭或 Escape 返回原预览，勾选框仍独立操作。
- 可以从“全部候选”手动补选。相同来源记录已在草稿时跳过，不自动合并跨来源的相同文本。
- 派生记录不参与此次抽样；预览后草稿变化时保留结果并要求核对后重新确认。
- 选取配置和最终身份清单在页面内存中记录；Mock 发布后规则在来源与修改页折叠展示。
- 本页最多选 5 个文件，体验范围及最终草稿上限为 10,000 条；字节限制和正式查询容量不通过此 Mock 验证。
- 比例的分母为当前条件筛选后的记录数。
- 原型算法标识为 `mock-fisher-yates-v1`，采用固定种子的演示打乱；不能当作正式统计或安全随机实现。
- **所有修改仅在当前页面内存中；刷新重置。** 此副本不作为跨浏览器共享状态、真实并发、服务端认证或性能测试环境。
- 分层、配额、模板、真实模型评分和语义去重未进入本次原型。正式 PRD、架构、Ticket、应用及部署不变。

2026-10-04 模型选样复核：10,000 条范围中，所选批次有 9,000 条有效评分、1,000 条未评测。选出的 500 条分数为 0–5，遍历 25 页确认分数升序，同批次重新预览得到相同身份；切换批次得到另一批结果。“仅选失败记录”的模型 B 候选为 5,384 条；模型 A 失败候选 5,415 条按 5% 向下取整选 270 条。仅含一条未评测记录时显示缺分空态，确认禁用；人工排除后新增 499 条，Mock 发布后的规则正确标识模型选样和评测批次。浏览器检查不证明真实评分可信度或正式服务性能。

2026-10-04 六项体验优化复验：Computer Use 确认数量 500 切比例默认 5%，分别修改后切回保留原值；输入未离焦即锁定旧预览且光标保持。重复抽中草稿已有记录时新增 0、确认禁用；随机恢复得到相同身份，更换种子得到不同身份。模型失败候选显示 `5,415 × 5% = 270`，人工排除后正常加入 5 条。筛选无候选时显示空态并禁用确认；整行点击及 Enter 打开完整记录，模型回答、0 分和完整 Metadata 均可查看，Escape 正常返回。桌面与窄窗口核对确认区位置和弹层，内联 JS 语法检查通过。
