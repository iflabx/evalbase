EvalBase Phase 1A 状态模型

用真实领域名称驱动一个纯内存状态机，观察单活跃工作草稿、多数据资产追加、正式 Schema 确认、候选快照与原子发布如何响应成功、阻断、失败、接管和受控删除。

本 Prototype 只回答一个问题用户能否在单活跃草稿、多资产追加、正式 Schema 确认和原子发布的状态模型中完成 v1/v2，并从所有阻断、失败和删除降级状态恢复？
运行边界：仅代表 VPN 内远程非生产、唯一真实 Project Owner / Sole Developer、允许分类的非敏感数据。Editor / Viewer 均为开发测试身份。原型不批准生产、真实多人、敏感数据、公网开放或 Langfuse API；这些均触发 Production Gates。Phase 1A 正式实现预期用服务器本地持久化承受正常重启/重新部署，但没有备份、RPO、RTO、SLA 或灾难恢复；本原型本身只保存在浏览器内存。
原型说明：状态对象、可执行事件与判断口径

状态对象

  • 运行边界、当前身份与编辑租约
  • 数据资产、解析视图与显式排除
  • 测试集、工作草稿与分资产映射
  • 正式 Schema、候选快照与测试集版本
  • 受控删除、最小墓碑、最近事件与审计

可执行事件

  • 上传、解析、排除、追加、映射、Schema 确认
  • 候选物化、发布、失败、同候选重试
  • 测试身份切换、确认接管编辑租约
  • 破坏性变化转新测试集、显式默认版本
  • 受控删除影响预览、二次确认和容量复检

每个事件先经过权限、租约、状态、Schema、数据分类和容量门禁。禁止事件可点击验证原因，但不会改变领域对象；页面始终重绘完整当前状态。
