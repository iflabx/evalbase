# 单人工作流原型 v5.1：上传队列与内容去重补充

2026-09-08，Project Owner 在冻结 v5 的基础上只补充上传行为：

1. 同一上传弹窗中重复点击“选择文件”时，新选择追加到现有队列；已选中的同一本地文件不重复列出。
2. 服务端按同一项目内原始字节的 SHA-256 识别重复。相同内容不进入字段映射或确认；界面说明已跳过，并在已确认时显示已有文件和所在数据集。
3. 同名但内容不同可上传；不同名但内容完全相同不可在同一项目形成第二份文件；不同项目允许相同字节。
4. 混合选择时只跳过重复文件，其他文件继续现有两步映射和一次确认。全部重复时不离开选择页，也不创建可见资产。

这不是测试记录去重、来源合并、跨项目引用、文件别名或重复管理功能。v5 其余页面、控件和流程保持冻结。
