# v2 共享草稿使用字段并发检查与草稿级唯一发布

- Status: Proposed
- Date: 2026-09-28
- Scope: v2；补充 ADR 0003/0004，不替换 ADR 0011 的版本存储协议。

## 背景

旧内部草稿使用独占租约，旧发布幂等以用户和请求键隔离。用户要求多人实时编辑、区分父版本草稿，且双人发布同一草稿只生成一个版本；这些要求不能由旧租约和请求幂等单独满足。

## 决策

新增持久化共享草稿实体，保留旧内部草稿作为兼容实现细节。每个父版本只有一个活动共享草稿，新建测试集草稿独立标识。字段 revision 检查允许不同字段并行保存，同字段冲突由用户明确解决；Metadata 暂按一个字段处理。

以 draft ID 建立唯一持久化发布结果，冻结已保存 revision，提交后关联唯一正式版本。不同用户、不同幂等键和重启重试都复用该结果。原有正式版本保持不可变，继续使用既有 Delta/Checkpoint 发布与读取协议。

## 取舍

不采用文本文字级 CRDT；本期字段为冲突单位，降低实现和恢复复杂度，同时保留用户输入。新草稿表增加迁移与清理工作，但避免把多用户语义塞进旧租约表及其每测试集唯一约束。数据库唯一约束、发布恢复任务和并发测试是必要成本。

## 依据与后果

[PRD](../PRD-evalbase-v2.md) 定义已确认业务规则；[架构](../architecture/evalbase-v2-architecture.md) 定义保存、同步、发布和故障恢复；[测试计划](../test-plan-evalbase-v2.md) 的 DRAFT/COLLAB/PUB 验证跨用户唯一性。不能以按钮禁用代替数据库保证。
