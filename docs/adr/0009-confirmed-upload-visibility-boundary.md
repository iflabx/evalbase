# 确认后创建数据资产

- Status: Accepted
- Date: 2026-08-31
- Decision role: Project Owner / Sole Developer

面向单人工作流的上传先形成可过期的待确认上传：服务端流式接收原始字节、计算哈希并生成解析预览，但在 Owner 确认前不创建领域可见的数据资产、来源说明或资料集合归属。确认动作以一个 PostgreSQL 可见性事务提交数据资产、诚实的环境级来源事实、资料集合归属和解析任务引用；取消、超时或提交前失败只留下可清理的临时对象，不进入日常列表。

待确认上传不是第二套数据资产状态机，也不能绕过 50 MB、格式、允许数据、Origin/CSRF、幂等或对象 commit marker 约束。确认响应丢失时以确认幂等键返回同一数据资产；确认后原始字节仍不可覆盖，解析失败仍保留已经确认的数据资产。
