# 取消与另存后的名称一致性修复

## 范围

- 当前交付名称从仍保留的交付计划读取。无来源对象的生成任务不再把最后生成名称作为任务对象；已移除交付的旧 run 保留并标记为历史候选。
- 原交付目标及会话名称保持原义；另存前展示将保存至的名称，成功后展示实际草稿名称，并与保存链接使用同一对象。成功名称随草稿当前名称读取，不改历史回执。
- 失败、拒绝、过期的保存请求不能显示为当前待保存目标；对象不可读时不猜测名称和链接。
- 不更改执行输入、历史步骤、幂等标识和预算。保留验收数据及旧预算。

## 验证计划

单元回归覆盖取消、另存待确认、成功、失效、不可读、跨交付和读投影不修改原始状态；隔离数据库真实 SDK 链路回归取消与另存的接口展示。

4217 只读 Computer Use 检查现有第18、20项会话，打开实际保存链接核对名称及条数。模型调用、生成和保存次数上限均为0，不重跑已通过流程。
