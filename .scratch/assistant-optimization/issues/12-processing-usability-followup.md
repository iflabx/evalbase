# OPT-12 数据处理操作连续性与核对体验优化

Status: ready-for-agent
Implementation: completed
Blocked by: none

优先级：P1（未提交配置丢失），其余体验改进 P2。2026-10-11 Owner 已单独授权完成 OPT-12 开发。以 OPT-11 已有实现为基础，后续沿用 `codex/assistant-optimization` 及同一 4217 隔离环境，一个 Ticket、一次人工 checkpoint。OPT-11 和其他 Ticket 的历史实施及 Owner 验收状态保持原记录。

## 目标与依据

让用户更容易开始处理、保留未提交操作、找到所需结果、连续核对变化并清楚保存成果。产品合同见 [PRD §6.4](../../../docs/PRD-data-selection-and-assistant.md#64-数据处理连续操作增补2026-10-11)，本张承接该合同的布局、实现边界与验收；继续遵守 [CONTEXT](../../../CONTEXT.md)、[处理架构](../../../docs/architecture/data-selection-and-assistant.md)、[ADR 0014](../../../docs/adr/0014-project-agent-and-processing-runtime.md)、[前端复用约定](../../../docs/architecture/phase1a-frontend-reuse.md)和[批次约定](../spec.md#整改批次执行约定)。

## 修改范围

### 1. 保留未提交配置（首要修复）

- 同一账号、项目、来源对象及浏览器标签页内，查看来源再返回、站内返回和浏览器前进/后退均保留选中身份、搜索/筛选、页码、处理方式、允许字段、要求及扩充数量。优先让“查看来源”在新标签页查看，原配置页保持可用；普通离开再返回仍须保留。
- 恢复先复核当前权限、来源及解析视图/草稿修订；发生变化时保留可恢复的要求并提示重新核对选取范围，不能默默改选全部、扩大字段授权或提交旧快照。已撤权内容不继续显示。
- 按账号、项目、来源隔离未提交状态；登出、切换账号清除，成功提交后清除对应待提交配置。前端标签页状态即可，不新增服务端“配置草稿”或浏览器长期正文缓存，不承诺关闭浏览器后的恢复。不能保证保留的离开路径给出明确提醒。

### 2. 首页入口与历史任务

- 页头增加主要操作“新建处理”。用现有 donor 选择组件选择当前项目中有权访问的原始文件、具体测试集版本或草稿，然后进入现有配置页；入口本身不创建任务。一次选择一个既有来源对象，不自动选择某个版本或草稿，不新增多步向导或另一套上传流程。
- 任务列表补文件/来源及处理要求摘要搜索、执行状态筛选和每页 20 项分页，搜索或筛选变化回到第一页。沿用当前最近 100 项的读取边界并明确显示该范围；查询、总数和分页口径一致，不冒充全部历史。
- 每行保留来源名、来源类型/版本（适用时）、处理方式、输入数量、发起人和时间；增加一行真实要求摘要，区分同文件多次改写。摘要缺失显示“未记录”，不生成虚构任务名，不建设任务重命名管理。
- 执行状态与保存情况分开展示。保存标识来自实际回执；只有能证明选中结果去重后的保存覆盖时才显示准确数量或“部分/全部已保存”，不能累加重放回执。旧数据无法证明覆盖时只显示“有保存记录”或“未记录”，不能把任务完成当成已保存。
- 首次加载、读取失败、确实无任务、搜索无匹配分别反馈；加载期间不能闪现“暂无处理任务”。无匹配提供清除条件入口。

### 3. 配置布局、选择和字段提示

- 桌面优先把宽度留给数据表，缩小设置区，保留已有吸顶；同时调整列宽、长文本换行和 Metadata 摘要，不能只缩右栏却继续遮住 Metadata。1280px 和 1440px 下常用三字段及选择操作应可扫读，不依赖横向滚动才能发现第三列。
- 1024px、480px 等无法舒适双栏的窗口使用上下布局，并提供紧凑的已选数量与“设置处理”定位入口；合法配置齐全时可提供对应开始操作。无需滚过整页记录才能找到下一步，固定区域不能遮挡分页、内容或键盘焦点。窄屏表内滚动允许，整页不得横向溢出。
- 将清洗、改写、扩充改为三个直接可见、支持键盘的 donor 选项；仅显示当前方式的一句说明及对应示例。清洗不填要求的确定性整理、改写含义、扩充新增数量继续准确区分。
- 将“勾选本页／选择全部匹配记录／已选 N 条／查看已选／清空”集中为紧凑工具栏：表头复选框表达本页选择，全选匹配的按钮明确总数量和范围；勾选取并集、取消仅影响相应身份，保持跨页选择规则。筛选外已选数量仍可见，完整已选集合才是提交范围。
- Metadata 字段名提供当前授权来源中已发现字段的候选及搜索，可手动输入未列出的合法字段名；不要求用户从长表里逐字复制字段名。保留既有固定比较方式及空值/缺失项规则，不新增表达式编辑器。
- 保留“允许修改的字段”，用简短说明明确其余字段保持原值；切换方式不重置要求、不扩大授权。输入、字段和数量不合法时在对应位置说明，开始按钮的数量与完整已选集合一致。

### 4. 稳定加载与准确状态

- 切换结果筛选、搜索或分页时保留任务摘要、工具栏和已选集合，只更新表格区域；显示加载反馈，避免整块结果消失及页面跳回顶部。只在必要时把焦点/视口移到结果区，连续核对返回时恢复原行位置。
- 新请求未完成时，旧表格必须标明仍是上一次结果，不能把旧行当作新条件命中项执行本页/全匹配选择。迟到响应不能覆盖较新条件或选择；请求失败保留已确认内容和输入，提供原地重试。
- 分开表达执行状态、自动数据检查和保存情况，移除“已完成 · 已完成”的重复。只有事实证明无执行失败、预期产物齐全时才可显示处理完成；空问题、重复等另外显示检查数量。真实未完成、缺失输出、失败、取消及可重试范围继续明确，不能仅凭计数相等判断成功。
- 将面向用户的“需核对”筛选改为“自动检查问题”，对应真实可定位的问题；任务级问题仍单独展示。0 个检查问题不表示内容正确或人工审核通过。仅有旧 `partial` 等粗略信息而无法辨明原因时保留不确定提示，不重写历史运行终态或放宽采用资格。

### 5. 结果查找与连续核对

- 保留“全部／有变化／自动检查问题”，补充问题、期望输出、Metadata 及可见来源名称搜索。搜索变化回到第一页；分类计数、分页总数、全部匹配选择针对同一完整授权范围和当前搜索条件，不能只过滤当前页。筛选之外的已选数量明确提示。
- 结果列表突出本次实际变化：例如只新增 `gbRisk` 时展示一次“新增 gbRisk：值”，去掉同一行重复的 Metadata 类别标签和相同变化文本。原字段摘要及完整 Metadata 仍可查看；空值、新增、修改、移除、字段顺序以及扩充的参考关系保持可辨认。
- 右侧详情新增“上一条／下一条”和“第 N 条，共 M 条”，按当前筛选/搜索下的稳定顺序跨页核对；首尾正确禁用，跳转不自动勾选记录。关闭后回到当前核对记录所在页及位置，焦点可恢复。
- 详情优先展示有变化字段和具体差异；未变化长正文可折叠，但完整前后内容必须可读。保留只读属性、勾选与开详情的独立行为、Enter 打开/Escape 关闭和按钮键盘访问，不在本张新增可编辑候选表。

### 6. 保存与已有成果反馈

- 按钮根据实际选择显示“保存所选 N 条”，无选择时禁用且原因明确。确认框继续展示数量、目标、追加/更新指定字段的区别；未选字段和正式版本保持原规则。
- 已有“已保存 N 条”及“打开草稿／打开原始数据”反馈继续使用真实持久回执，刷新可恢复；结果页和任务列表的保存口径一致。追加已有草稿与更新来源草稿不能混淆；本张不新建成果状态表或自动采用。
- 保留失败输入、草稿修订冲突及未知写入的原请求/幂等键对账。界面简化不得使未知写入可以换键重复追加，也不因重复打开确认框而宣称全部已保存。

| 位置 | 布局与控件顺序 | 必须保留的状态 |
| --- | --- | --- |
| 处理首页 | 标题/新建处理 → 搜索与状态筛选 → 紧凑任务表 → 分页 | 加载、无任务、无匹配、失败；执行与保存分别表示 |
| 配置页 | 来源摘要 → 搜索/Metadata 条件/选择工具栏 → 数据表；紧凑三方式/字段/要求/数量/开始 | 配置保留、字段保护、筛选外选择、来源变化和禁用原因 |
| 结果页 | 执行/检查/保存摘要 → 搜索与分类 → 选择/保存 → 变化列表 → 分页 | 加载不移除工具栏；选择、错误、旧数据与当前条件可区分 |
| 核对详情 | 位置及前后导航 → 本次变化 → 按需完整对比与来源 | 只读、跨页、首尾禁用、关闭位置与焦点恢复 |
| 保存确认 | 数量/目标 → 追加或更新说明 → 取消/确认 | 提交、冲突、未知结果、真实回执 |

## 实施边界与次序

1. 先修配置保留，再做稳定加载和桌面布局、连续核对，最后补入口、任务查找及筛选/保存表达；这是同一张 Ticket 的实施顺序，不拆成多次人工 checkpoint。
2. 复用现有来源浏览、processing 输入/运行/结果、Metadata 条件、选择、回执和共享核对组件。实施前列实际调用方及路由处置；确实缺少结果搜索、字段候选或窄保存摘要时，仅扩展现有读取接口的必要参数/字段，不默认新增公共路由、表、迁移、依赖或通用状态框架。
3. 正文保持服务端授权分页；字段候选和全量统计有界计算，不把 10,000 条正文加载到浏览器再搜索，不逐行发请求，不增加高频轮询。普通查看不调用模型，本张不承诺未经测量的延时指标。
4. 共享组件影响到项目助手时同步核对展示；助手仍读取同任务的全部有效候选，保持多批/局部替代、个人背景权限、固定确认和返回原会话。不得把手动单运行范围套到助手，或改写助手规划、调度、工具权限及模型配方。
5. 复用原始来源、三字段/空 Metadata、CAS、幂等和容量规则。不重做整站、任务命名平台、通用工作流、自动语义审核或历史重写；不修改服务器其他项目。
