# OPT-04：助手工作区与单会话实用闭环

Status: ready-for-human
Implementation: completed
Blocked: none

## 合同与范围

按 Owner 持续目标执行 [Spec](../spec.md) 和 [优化合同](../../../docs/assistant-optimization.md)。复用个人会话、已有处理任务和确认操作；背景文件使用 OPT-03 公开接口。冻结原型及 frontend-v1 保持只读。

## 前端对照与覆盖

| 项目   | 已确认行为与呈现                                                                                  |
| ------ | ------------------------------------------------------------------------------------------------- |
| 工作区 | 扩大既有 Sheet，左侧对话和输入，右侧常驻背景、当前任务与候选；窄窗口上下排列且区域内滚动          |
| 顺序   | 标题、会话选择、当前页面范围；对话；输入。右侧背景、目标与状态、候选审核                          |
| 背景   | PDF/MD/TXT 上传、容量、文件列表、按真实页/行查看；上传成功后留在原会话，刷新保留                  |
| 删除   | donor AlertDialog 说明会清除当前会话正文及未采用任务正文；已采用数据保留；失败保留列表并可重试    |
| 状态   | 提取中、等待执行、真实处理进度、待审核、待确认、失败恢复；不以模型文字替代实际回执                |
| 风格   | 直接使用 frontend-v1 donor Sheet、Button、Dialog、AlertDialog、Table、输入组件、token、字号和间距 |
| 边界   | 无新账号/项目、无额外技能平台、无常驻知识库、无生产部署或 main 合并                               |

## 公开反馈循环

浏览器上传真实 MD 字节，打开引用预览，刷新核对；确认删除后列表及正文同步。核对桌面侧区在对话滚动时保持可见，窄屏无页面横向溢出。其后真实模型、GB PDF、ChineseSafe 原资料以一个会话创建新的 200 条版本，完整核对和导出。自动化数据不得作为最终实用闭环的替代。
