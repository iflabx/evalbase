# OPT-24 独立项目助手页面与会话工作区

Status: ready-for-agent
Implementation: not-started
Blocked by: OPT-20

优先级：P1。当前仅授权方案/Tickets；推荐在 OPT-23 后串行实施，避免来回接线。布局与行为以 [总方案 §6、§8](../../../docs/assistant-workspace-reliability-plan.md) 为准；UI 严格复用 [frontend-v1 donor 约束](../../../docs/architecture/phase1a-frontend-reuse.md)，正式代码只改 `frontend-v3/`。

## 目标

助手有可刷新、可返回的独立地址，聊天、背景、要求、进度与结果可以在同一页面连续使用。完整迁移现有能力，不因页面重做丢失会话或确认入口。

## 实施范围与对齐表

| 页面部分 | 控件与顺序 | 状态和边界 |
| --- | --- | --- |
| 入口/路由 | 项目侧栏入口；`/projects/:projectId/assistant` 和 `/:sessionId` | 已有顶部/对象入口导航至此；旧完整抽屉退出正式入口；刷新不创建会话/运行 |
| 会话栏 | 新会话、按名称搜索、会话列表、更多中的重命名/删除；可收起 | 复用本人会话分页/API；空态、失效链接、无权限明确，删除沿用现有确认及资源规则 |
| 页头/聊天 | 会话名、真实状态、按需停止/恢复；消息；对象标签；输入框 | 一处显示当前状态，工具历史折叠；失败保留后来输入，无思维链或虚假百分比 |
| 工作区 | 结果、资料与要求两页签；方案/历史明细展开 | 迁移现有候选及固定确认能力，明确当前批次范围；整任务聚合由 OPT-25 替换 |
| 输入 | 选择资料、背景附件、简短示例和发送 | 示例只填入；不自动上传/执行；运行中可编辑未发送文字，沿用单会话执行边界 |
| 窄窗口 | 收起会话栏，聊天/工作区切换 | 输入/选择/滚动保留；表格内部滚动，页面不横向溢出 |

- 使用总方案定义的默认对话、审核分栏和展开结果布局，不引入拖拽/dock 库。模板、按钮、字体、色彩、边框、tooltip 和加载过渡复用 donor。
- 对象页带入已验证的现有上下文；界面区别当前页面对象与正在执行任务对象。只导航不改变任务；未冻结选择不声称已带入选择范围。
- 支持安全 Markdown 的段落、列表、代码和简单表格，禁止原始 HTML、外部嵌入及执行式链接；不把模型输出转换成可执行确认卡。已有提示中“禁止 Markdown”随真实渲染支持收敛，避免两套冲突格式。
- “按方案执行”沿现有消息提交合同表达用户意图，绑定当前方案修订，不新增任意工具执行接口。
- 初始按需读取清单、状态和分页消息；结果/背景明细懒加载。活跃才进行现有周期轮询，隐藏页减频或暂停，待确认/终态停止；恢复前台重新核对。
- 切换项目/会话取消旧请求，查询键隔离账号/项目/会话；403 清理未授权正文。无后台 SSE/WebSocket 改造，不重建另一套 frontend task state。

## 验收

| 编号 | 验收 |
| --- | --- |
| R24-1 | 三类旧入口到达正确对象/个人会话；深链接刷新、前进后退、失效链接和新会话空态正确；不会创建重复消息、会话或任务。 |
| R24-2 | 同会话背景、要求更正、方案执行、停止/恢复、现有候选审核和确认保存能力完整迁移；重命名/删除行为及已产出业务资产保留。 |
| R24-3 | 桌面空态、执行中和审核态与 donor 风格一致，笔记本及窄窗口无挤压/横向页面溢出；键盘可达，切页签不丢输入或选择。 |
| R24-4 | Markdown 不执行 HTML/链接指令，不生成伪确认卡；跨账号/项目或角色降级无法读取未发布正文。 |
| R24-5 | 首屏不读全量候选/背景；轮询响应不带全部消息/结果；待确认停止活跃轮询；旧响应不覆盖新会话。记录请求数、字节及分阶段耗时。 |
| R24-6 | 只看方案不写入；按钮执行使用最新方案；运行中编辑但未发送文字不成为要求。来源标签变化不暗改当前运行范围。 |

使用现有浏览器测试覆盖本页主要流程和关键状态；底层业务不变的全量后端测试不重复。无原型工程/全站截图基线要求。部署后复用同一 4217 数据，最终整体验收在 OPT-25 完成后集中进行。
