## 实施边界

复用 processing-preparation 与 executionPlan，把明确的首尾空格规则、真实来源、实际记录ID和哈希固定为内部 command；模型的二次参数不覆盖该命令。只规划和停止不执行；未决来源/范围仍澄清。内部 command 不进入展示或模型上下文。新方案预校验不绑定旧命令，实际执行核对当前 requirementsKey，继续通过权限和来源哈希检查。保存目标复用 saveTarget 和固定确认回执。
