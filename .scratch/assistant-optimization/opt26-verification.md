## 修改与边界

- 计划步骤按 action 派生实际工具参数合同；已知输入只允许该工具的字段及类型，未来引用仍可省略，真正执行继续补齐绑定并校验。原始文件/草稿/正式版本的来源形状在副作用前检查，背景文档不转换成原始资产。
- 内部错误只解释当前工具、错误位置及允许字段，移除计划校验失败时附送的整段跨工具教程。格式纠正和重复失败仍使用原预算与回执，连续同错明确停止，不增加重试循环。
- 普通操作记录显示业务反馈，内部 hint 进入原生折叠详情；旧会话未标来源的问题默认作为诊断，不根据最后一轮状态猜测。仅服务端确认的业务要求问题直接显示，正常业务提示仍保留。
- 保留真实成功回执和成果链接；调整模型连接/来源/内部参数等错误的用户说明。明确当前能力不支持仅凭背景文档从零生成，该能力仍归 OPT-29。
- UI 仅复用 frontend-v1 风格的现有卡片、文字颜色与原生 details/summary，无新增 CSS 体系、依赖、数据表或外部 API。遥测标记为 `assistant-tools-v5`、`assistant-prompt-v6`。
