## 3. 共用实施约束

1. **一份事实与输入合同。** 业务 Schema 同源生成工具声明，身份/权限/令牌/幂等键由服务端绑定。当前要求、交付、来源范围、保存目标分别有真实身份，展示是只读投影；不恢复多份 steps/stage/nextAction 共同驱动。
2. **有界纠正与可靠结果。** 只做无损协议归一；参数反馈、业务冲突、传输错误和正常中断分开。暂停/查询/继续使用同一持久任务与账本，未知写入先查原回执。模型口头成功不替代事务回执。
3. **覆盖人工能力但不绕过用户。** 原生文件、密码/key、确认和下载由受控页面协作；其他业务动作须有真实工具操作，不能用链接跳转冒充接入。简单明确操作不增加审批层。
4. **必要结构调整允许。** 以真实调用者和根因选修改范围；抽取共享业务合同、移出旧反向依赖、替代旧重复机制均在范围内。不为每个按钮建工具或多层包装。
5. **保留与退出分开。** 旧执行/计划/纠错/续步退出新路径；旧会话、成果、账本及删除保护保留。处理 Worker 内部 AI SDK 可继续使用。新旧执行器不共同推进同一任务，不失败自动回落。
6. **验证材料与业务数据隔离。** 只读核验既有验收数据/旧预算及关闭时间；新写入、删除和故障测试使用独立合成对象/隔离库。新迁移增量实施，不能为测试重建或清空验收数据库/对象卷。
7. **授权和部署。** 当前只开票；后续明确开发/验收授权覆盖的步骤按票执行，不另加流程性审批。新增真实活动在执行前登记上限；超出范围或上限不能自动追加。更新 4217、正式部署、合并、推送仍按实际授权范围处理。
8. **文档与检查适度。** 各票只读受影响合同，复用未改变的证据；定向检查和一次适用关闭审阅按 AGENTS.md，不机械重跑全库。不引入多智能体平台、工作流编辑器、向量库、额外判断模型、任意网络/电脑操作或第二套会话后端。

## 4. 定向验证与有限 Computer Use

### 4.1 分层证据

- 每票先在真实公开业务入口验证自己的合同，使用真实 SDK + 本地可控 HTTP/数据库覆盖参数错误、竞争、超时、摘要、撤权、恢复和幂等。可控模型测试的外部请求为 0，不伪称真实模型成功率。
- 前端用真实页面/事件夹具核对点击、选择交接、附件、失效确认、跨会话迟到响应、流重连、键盘及窄屏。样式对照只记录受影响控件，最新原型整页未复验的事实保留。
- 下列 C01～C08 是 **8 个新正式接入样本**，不是历史第 1～20 项重跑。每项一个独立新会话，项内不换会话救场。源数据、文档和账号使用可核对的合成小材料；普通提示可随真实材料名称等价替换，不能塞内部 ID、Schema 或工具修复步骤。
- REBUILD-08 的历史/删除浏览器检查以及权限、追加额度、故障注入等受控回归，不额外消耗这些真实模型预算。实际模型/CU 未运行不得写为通过；工具不可用则明确缺口，不由脚本伪造页面成功。

普通业务澄清和必要确认允许；每项最多一次普通继续用于观察错误恢复，计划内暂停后的继续不消耗额外重跑资格。达到无进展/纠错/服务限制或需技术救援时保留首错并停止，不换模型、加内部参数或用后端补数据救场。未知写入只查原回执。修复后重测使用另行授权的新有界记录，不能重置本活动或借用旧余额。

原适配 L02 的环境干预、C1/C2 的样本/时序缺口保持原判定。正式接入以新版本的真实 SDK 受控错误和 C02/C08 无环境救援闭环提供替代证据，并注明不是原同版本整轮门槛重验。是否更稳定需要另外同条件对照，不是本批交付前提。

### 4.3 执行前和结果记录

执行前完成只读预检：固定代码、模型配置/依赖锁/工具Schema、普通与模型 Worker、隔离账号和数据引用；失败即在模型请求前停下修复设施。新活动记录限额、材料哈希和保护对象清单，不复制凭据进 manifest。旧活动原值/关闭时间及验收成果摘要前后核对。

每票一份主要 verification 记录，最低包含：实现 SHA、能力编号/公开入口/角色、真实 SDK 参数链证据、测试命令与结果、首错/纠正/澄清/技术干预、实际请求及结果/回执、未覆盖项。CU 同时记录 safetyResult 与 businessResult；保护性停止不是业务通过。截图与事件使用新目录，不覆盖旧附件和 audit 文件，不保存明文秘密。
