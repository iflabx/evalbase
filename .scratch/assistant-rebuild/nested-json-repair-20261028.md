# 嵌套结构恢复补修

基线 5d6449b，分支 codex/assistant-rebuild。

仅为 schema 明确要求对象的结构字符串恢复缺失的单个根闭合符；必须以完整容器或字符串值结束，追加后严格 JSON 解析。不猜测内容、不截掉尾部、不放宽字段保护。解析失败或超过已有长度上限直接安全失败，避免必然失败的模型纠正。普通文本不进入结构解析。继续复用规范对象的遗漏字段继承与深层比较。

新增 SDK 回归覆盖分块流输出、根闭合缺失、额外未知字段纠正时遗漏目标、不可恢复零纠正；unit覆盖持久pending恢复、数量篡改拒绝、普通文本、长度上限及不同完整结尾。旧 C01/C02 回归保留。审查发现普通文本误判、超限空耗纠正，均补修。执行过程区分参数纠正与要求保存，沿用既有组件。

模型配置仍为qwen-new、应用temperature=0，不猜测部署别名底层模型或调整服务采样。未改生产/main/GitHub；验收沿用隔离4240，另建限额活动，旧数据和旧预算保持。详细验证及CU证据在 nested-repair-20261028 与 nested-cu-20261028。
