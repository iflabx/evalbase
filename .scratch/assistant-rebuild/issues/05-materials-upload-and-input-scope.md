## 问题与目标

旧工具不覆盖集合、上传/映射/移动等页面操作，聊天入口也不能天然获得用户真实勾选和原生文件。

目标是交付本票列明的真实行为，允许解决共同责任冲突所需的结构调整。不能用局部提示词补丁、原型按钮或 Helper 单测代替业务闭环，也不借本票扩张未批准功能。

## 修改范围

1. 接项目可见列表、创建、当前上下文和导航，接集合/文件/统一记录查询、集合创建与同项目移动；复用领域服务。导航改变不改变在途执行绑定的项目。
2. 通过 REBUILD-04 原生文件桥完成待确认上传、映射预览、固定确认/取消和未映射文件的初次映射；沿用文件格式、容量、重复字节与不可变原件规则。
3. 接列表当前页/全部匹配/已选记录的范围交接，服务端固定真实 ID、来源身份和修订；来源失效/改动必须重新核对，不能默默改成整文件。
4. 接背景 PDF/MD/TXT 上传、私有文档目录、真实片段/页行/引用；沿用既有大小和数量上限，背景不是测试记录。文档指令不能授予权限，不能为 GB 或某个文件名写专门流程。
5. 读取使用有界原文/分页，准确标明截断；到处理/助手的入口只传合法上下文，不伪称已提交。A05 背景删除与检查点清理由 REBUILD-08 接入。

## 主要修改位置

- 资料、上传、映射、项目查询与成员权限的现有服务/路由。
- src/assistant-rebuild/ 的领域工具注册与背景引用。
- frontend-v3 原始数据页、上传映射组件、assistant-input-context 及动作桥。

以上为实际调用点导向，不是强制目录设计；已有清晰函数直接复用。未列出的受影响调用者可一并调整并在验证记录说明，不增加无真实调用者的通用层。

## 验收标准

- [ ] **R05-1** P/M/A04 每个编号有真实工具或明确原生桥接；创建集合/移动文件至少一个旧十五工具外写能力经普通提示完成，非仅跳转原页面。
- [ ] **R05-2** 原生选择→映射预览→用户确认后才形成原始文件；取消/过期不形成已确认资料；重试不重复上传，原件字节和字段值保持。
- [ ] **R05-3** 真实 UI 勾两条进入助手只看到对应固定范围；“本页”“全部搜索结果”“全部文件”语义不混，空选/过期选择不扩成全部。
- [ ] **R05-4** 查看权限、跨项目对象、移除成员及私有背景访问均由服务端正确限制；导航不能让旧任务借新项目授权。
- [ ] **R05-5** 非 GB 小文档可被真实引用，页行/片段不是编造；原文截断、缺失或解析失败显示实际情况，未读全文不声称已读完。
- [ ] **R05-6** 完成 C03：普通提示创建/移动资料并查询真实页面勾选范围，读取上传的小背景；原件保持，无处理或生成任务副作用。

- [ ] **R05-7** 覆盖旧 failed discovery→continue 场景：发现失败并经历普通继续后，用户明确给出可见文件名时，应重新核对并绑定该真实来源；不得一直返回旧候选列表。既有预算/纠正记录保留，来源未确定前不创建作业。
- [ ] **R05-8** 覆盖旧 explicit new filename 场景：页面当前对象 A 与用户明确要求的对象 B 不同，按可见目录核对并绑定 B，旧候选/页面上下文不能覆盖新要求；同名歧义才澄清，跨项目或不可见对象仍拒绝。以真实业务引用和受控 SDK 证明范围正确，不要求用户提供内部 ID。
