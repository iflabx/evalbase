# 停止后修改保存目标的恢复补修

日期：2026-10-29。范围：旧组合场景暴露的停止后改名、继续、确认重建与唯一保存；不重跑 C01/C02 或已通过的上传、发布用例。

## 实现

- 以处理操作记录绑定的不可变要求事件判断结果兼容性。只改交付名称/保存目标时复用原处理结果；来源、范围、处理方式、数量、字段或处理要求变化时不复用。
- 用户暂停在要求修改后保留；普通查询和单独改名不恢复执行。明确继续才恢复，恢复授权限于当前执行轮次并在结束时清除。
- 保存按处理身份及当前要求修订创建操作；旧卡失效、新卡使用新名称，重复确认复用原回执。兼容同修订旧操作键。
- 查询、调度唤醒、等待处理与准备保存共用结果兼容性判断。未改前端样式、未新增数据表或迁移。
