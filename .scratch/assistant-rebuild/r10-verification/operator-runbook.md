# REBUILD-10 受控切换与人工回退

本票仅在隔离测试数据库演练；以下命令给已授权操作员使用，不授权切换4217或正式环境。运行前加载目标部署既有环境，核对数据库、桶、版本和三个进程身份；不得把验收私有环境文件提交仓库。

## 停用助手

1. 先停止/排空旧版本Web派发，核对活动turn、处理作业、确认与真实回执。旧二进制不识别新屏障，不能只更新数据库后让它继续运行。
2. 在同一固定版本执行 `node dist/server/src/scripts/assistant-mode.js status`，再执行 `node dist/server/src/scripts/assistant-mode.js manual`。命令先提交持久屏障，再封存新运行时执行权；重复运行可继续对账。
3. 核对返回的模式、暂停对象、在途作业与真实回执。未知请求不退款：迟到的可信HTTP结果只补全实际用量/时长并保留未知历史，不能恢复旧执行权或提交迟到业务。
4. 等助手归属作业有界终结，保留成功批次。作业归属依据当前服务端executionOrigin及确切运行引用，人工续作/显式人工重试不因历史来源被停掉。
5. 用人工页面继续上传、编辑、处理、保存、发布、下载；旧会话兼容读取，旧执行/最小验证接口410。屏障只停新助手执行，既有真实回执可查且重复确认不重写。

## 重新启用

清理/核对在途助手作业后，执行 `node dist/server/src/scripts/assistant-mode.js rebuild`；未结算时命令拒绝并保持manual。启用不自动恢复暂停任务；用户明确继续才沿原任务/预算恢复。不得把新检查点交旧引擎，不降级数据库或重置旧预算。

增量迁移只在不存在模式行时插入rebuild，不覆盖manual。状态命令只读。编译产物、Web及ordinary/model Worker须同一SHA；仅有构建成功不能证明已更新环境。隔离演练、实模和旧数据审计证据见[本票记录](verification.md)。
