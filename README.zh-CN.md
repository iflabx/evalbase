# EvalBase

[English](README.md) · [文档导航](docs/README.md) · [启动与配置](docs/getting-started.md)

EvalBase 是面向团队的测试数据管理应用，把原始资料整理、记录选取、共享草稿、模型处理和项目助手放在同一个工作区，帮助用户将资料或生成候选整理成**可追溯、可协作、可版本管理的测试集**。

适用于意图识别、实体提取、智能体工作流、安全测试等数据集准备场景。每条测试记录由**问题、期望输出和 Metadata** 组成。执行评测、收集被测模型的实际回答属于后续评测环节。

## 主要功能

| 功能       | 可以做什么                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| 项目与权限 | 使用独立账号登录，按项目管理成员及编辑、查看权限。                                                           |
| 原始数据   | 上传 CSV、JSON、JSONL，按资料集合整理文件，映射字段并保留原件。                                              |
| 筛选与选取 | 搜索和筛选记录，选择全部匹配内容或随机抽取；预览固定结果并人工调整后加入草稿。                               |
| 测试集     | 多人共同编辑草稿、字段离焦自动保存与冲突处理，发布不可变版本，查看修改和来源，导出数据及溯源。               |
| 数据处理   | 清洗、改写、基于记录扩充，或依据背景文档生成；核对候选，并在同一任务工作区继续多轮处理。                     |
| 项目助手   | 用自然语言查找资料、设计方案、准备草稿、处理记录和核对结果；在独立会话页面上传 PDF、Markdown、TXT 背景文档。 |
| 模型设置   | 管理员配置 OpenAI 兼容服务、凭据和可选模型；凭据保留在服务端。                                               |

## 如何使用

**整理原始资料或上传背景 → 选取记录或设计生成方案 → 核对和修改候选 → 确认保存到草稿 → 发布版本 → 导出。**

从现有数据出发时，可以先映射和选取，再清洗、改写或扩充。只有背景文档时，也可以让项目助手先设计方案，再依据文档生成候选。

数据处理先产生候选，保存结果和发布版本分别确认。草稿在离开字段后自动保存，“已保存”表示服务端已经确认；光标仍在字段内的最新输入尚未提交。生成内容和模型审核结果仍需要人工核对。

## 启动与配置

[启动说明](docs/getting-started.md)包含本地安装、首个管理员初始化、模型 Worker 配置和开发命令，也说明默认 `compose.yaml` 的旧版测试设置与当前账号、模型处理配置的区别。

## 架构

| 组件             | 职责                                                                                |
| ---------------- | ----------------------------------------------------------------------------------- |
| React Web        | 正式前端位于 `frontend-v3/`，使用 TanStack Router、TanStack Query 和 Tailwind CSS。 |
| Fastify Web 服务 | 账号、权限、业务 API、助手请求及正式前端静态文件。                                  |
| 普通 Worker      | 非模型后台任务和清理。                                                              |
| 模型 Worker      | 模型处理任务；复用同一 Worker 入口，设置 `WORKER_TASK_GROUP=model`。                |
| PostgreSQL       | 账号、项目状态、草稿、版本、作业、助手进度和操作回执。                              |
| MinIO            | 原始文件、处理产物和导出文件。                                                      |

项目助手使用 AI SDK 和 OpenAI 兼容模型接口，应用负责持久化要求、执行进度、预算和真实业务回执，业务操作受当前用户权限约束。细节见[架构说明](docs/architecture/data-selection-and-assistant.md)和[运行时 ADR](docs/adr/0014-project-agent-and-processing-runtime.md)。
